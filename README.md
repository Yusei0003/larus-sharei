# larus-sharei

ラルスに関わる帯同審判・帯同MC・その他従事者の謝礼に係る支出を管理するためのものです。

KESEN LARUS BASKETBALL CLUB の「交通費等及び謝礼金支給規程」第5条（帯同審判謝礼金）・第6条（コミッショナー謝礼金）等に基づき、対象者への謝礼金を取りまとめるWebアプリです（交通費取りまとめアプリとは別管理）。データはFirebase（Firestore + Authentication）に保存され、共有の合言葉でログインした端末同士でリアルタイムに同期されます（PC・スマホなど複数端末から同じデータを見られます）。ログイン用のアカウントは交通費取りまとめアプリと共通のため、同じ合言葉でログインできます。

## 使い方

0. `index.html` をブラウザで開く（GitHub PagesのURL、または `python3 -m http.server` 等で配信）。ログイン画面が表示されるので、共有の合言葉（交通費アプリと同じもの）を入力します。**`?key=合言葉` を付けたURL**（例: `https://.../?key=xxxxxx`）を開いた場合は、この入力なしで自動的にログインされます。LINEなどでリンクを共有する際はこの形式のURLを使うと、ブラウザの種類やアプリ内ブラウザかどうかに関係なく毎回確実にログインできます
1. **入力タブ**: 日付・区分（帯同審判／コミッショナー／その他）を選びます
   - **帯同審判**: 試合種別（練習試合／公式戦）を選びます。練習試合の場合は活動場所（気仙管内／気仙管外）・拘束時間（半日／1日）で支給額が決まります。公式戦の場合は1試合2,500円で、担当した試合数（最大3試合）を選ぶとその分がまとめて計算されます
   - **コミッショナー**: 活動場所（気仙管内／気仙管外）を選び、担当した試合数（最大3試合）を選ぶと支給額が自動計算されます。気仙管内は謝礼1,000円×試合数、気仙管外は謝礼1,000円×試合数に加えて交通費1,000円（1日1回のみ・試合数に関わらず定額）が上乗せされます（例: 気仙管外で2試合担当した場合は謝礼2,000円＋交通費1,000円＝合計3,000円）
   - **その他**: 上記に当てはまらない従事者への支払い用です。内容（自由記述）と支給額を直接入力します
   - 対象者は、よく依頼する人をプルダウンから選ぶか、「その他（自由入力）」を選んでその都度お名前を入力できます
   - 「登録する」を押すと記録されます
2. **一覧タブ**: 登録済みの記録をスプレッドシート風の表で確認・支給額の修正・削除。月や氏名で絞り込み可能です
3. **対象者の登録・削除**: 入力タブ下部の「よく依頼する対象者の登録・削除」から、頻繁に依頼する人の名前をあらかじめ登録・削除できます。ここに登録していない人への謝礼は「その他（自由入力）」でその都度入力してください（過去の記録に影響はありません）

## データの保存先とログインについて

このアプリはFirebase（Firestore + Authentication）を使ってデータを保存しています。交通費取りまとめアプリ（別リポジトリ）と同じFirebaseプロジェクト・同じログインアカウントを使っていますが、データ領域（コレクション）は別（`sharei_records` / `sharei_meta`）です。

- **アクセス制限**: 交通費アプリと共通のFirebase Authenticationアカウントでログインします。合言葉（パスワード）を知らない人はデータを閲覧・編集できません
- Firestoreのセキュリティルールは交通費アプリ側で設定済みの「ログイン済みユーザーのみ読み書き可（`allow read, write: if request.auth != null;`）」がそのままこのアプリのデータ領域にも適用されるため、このアプリのために追加のルール設定は不要です
- 合言葉を変更したい場合は、Firebaseコンソール → Authentication → Users タブから、共有アカウントのパスワードをリセットしてください（交通費アプリ側と共通のパスワードです）
- **接続にはインターネット接続が必要です**

### 合言葉入りURL（LINE共有用）

`https://（GitHub PagesのURL）/?key=（合言葉）` の形式でURLを作ると、開いた瞬間に自動でログインされます。交通費アプリと同じ仕組みです。詳しくは交通費アプリのREADMEをご参照ください。

### firebase-bundle.js について

`firebase-bundle.js` は、Firebase JS SDKと `firebase-entry.js`（初期化コード）を [esbuild](https://esbuild.github.io/) でひとつのファイルにまとめたものです。外部CDNに依存せず動作します。`firebaseConfig` を変更した場合など、再ビルドが必要なときは以下を実行してください。

```
npm install firebase esbuild
npx esbuild firebase-entry.js --bundle --format=iife --platform=browser --minify --outfile=firebase-bundle.js
```

## キャッシュ対策（アセットのバージョニング）

`.github/workflows/version-assets.yml` により、`main` ブランチへのpushのたびにGitHub Actionsが自動的に `index.html` 内の `app.js` / `style.css` / `firebase-bundle.js` の読み込みURLへ `?v=YYYYMMDDHHMMSS`（UTC・push時刻）を付与するコミットを追加します。これにより、コード更新後にブラウザの古いキャッシュが表示され続ける問題を軽減します。GitHub Pagesの設定変更は不要です（Deploy from a branch のまま動作します）。
